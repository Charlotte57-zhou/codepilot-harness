# Roadmap

## Next

- Add signed Windows builds and release provenance.
- Test real-provider smoke flows in a credentialed, non-recording release job.
- Improve keyboard navigation, narrow-window behavior, and accessibility evidence.
- Add explicit transcript export/redaction UX.

## Later

- macOS/Linux packaging after OS-specific vault, shell, and worktree behavior is verified.
- Stronger process isolation for shell tools.
- Broader MCP lifecycle and failure-recovery testing.

## Deliberately out of scope

- A hosted multi-tenant agent service.
- A general provider marketplace.
- Compatibility imports for private pre-0.1 state.
- Claims of complete parity with Claude Code or Codex.
