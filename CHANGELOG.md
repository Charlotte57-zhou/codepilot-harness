# Changelog

## 0.1.0 - 2026-08-08

- Published the local Electron coding-agent harness as the first clean public source release.
- Made WorkspaceTarget, Run, transcript tool results, Task progress, provider profiles, and saved registry formats current-schema-only breaking contracts.
- Added SDK built-in filesystem path validation before permission execution.
- Fixed resumed runs to restore the latest task and frozen run preferences.
- Added an allowlist-based source exporter, privacy scan, reproducible manifest verification, CI, governance files, and a bundled demo Skill.
- Removed the hosted interview deployment, historical migration paths, third-party logo assets, and unsupported provider presets from the public scope.

There is no upgrade path from pre-0.1 private runtime state. Start with a fresh application data directory or remove old local CodePilot state.
